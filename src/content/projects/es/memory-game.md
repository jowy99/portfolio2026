## Resumen

- Juego de memoria en el navegador
- Pensado para partidas cortas
- Diseño y desarrollo propios

## Objetivos

- Crear un juego simple y accesible
- Implementar una lógica clara y estable
- Mantener una interfaz limpia

## Retos

- Mantener la lógica ordenada
- Evitar complejidad innecesaria
- Que la dinámica se entienda a la primera

## Decisiones técnicas

- Lógica interactiva con JavaScript
- Estructura con HTML
- Estilos con TailwindCSS

## Destacado

- Cuenta atrás de 30 segundos
- Contador de aciertos y movimientos
- Mecánica intuitiva

## Resultados / Impacto

- Juego terminado
- Código disponible en GitHub

## Aprendizajes

### Lo que aprendí

- Lógica de juego en JavaScript
- El valor de un diseño sencillo

### Qué haría mejor

- Añadir niveles de dificultad
- Incluir estadísticas de partidas
