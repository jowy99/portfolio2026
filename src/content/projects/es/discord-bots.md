## Resumen

- Varios bots de Discord desde 2021
- Sobre todo de moderación
- Hechos a mano, salvo el de Defiance, con IA

## Objetivos

- Automatizar la moderación de servidores
- Añadir funciones para cada comunidad
- Practicar con Node.js en casos reales

## Retos

- Adaptarse a las necesidades de cada servidor
- Coordinar reclutamiento y convocatorias en Defiance
- Conectar un bot con la web del club

## Decisiones técnicas

- Desarrollo con Node.js
- TypeScript y discord.js en los más recientes
- Comandos de barra
- SQLite en La Lonja

## Destacado

- Warlock Club, SpArTa, Anham, Translator, WoWLK, Helper y ACWO Bot
- Vendetta, para un servidor privado de World of Warcraft
- La Lonja: encuestas y recordatorios
- Defiance: reclutamiento, pruebas y votaciones

## Resultados / Impacto

- Usados en servidores de Discord
- Evolución hacia TypeScript y datos persistentes

## Aprendizajes

### Lo que aprendí

- Resolver problemas reales de otras personas
- Practicar JavaScript fuera de clase

### Qué haría mejor

- Partir de una base común
- Añadir tests a los comandos
