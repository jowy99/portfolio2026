## Resumen

- App en Laravel para organizar comidas
- Platos con ingredientes y etiquetas
- Agrupados en menús

## Objetivos

- Guardar platos con sus imágenes
- Crear menús a partir de esos platos
- Administrar el contenido desde un panel

## Retos

- Modelar las relaciones entre tablas
- Gestionar las imágenes de cada plato

## Decisiones técnicas

- Laravel con plantillas Blade
- Controladores de una sola responsabilidad
- Relaciones definidas con migraciones

## Destacado

- Alta, consulta y edición de platos
- Creación de menús
- Panel de administración

## Resultados / Impacto

- Aplicación con migraciones, controladores y vistas
- Código disponible en GitHub

## Aprendizajes

### Lo que aprendí

- Relaciones entre tablas en Laravel
- Separar el código en controladores pequeños

### Qué haría mejor

- Añadir tests
- Documentar la instalación
