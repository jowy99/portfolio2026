## Resumen

- Aplicación del tiempo para cualquier ciudad
- Interfaz moderna y minimalista
- Datos de WeatherAPI

## Objetivos

- Practicar el consumo de APIs externas
- Gestionar el estado en React
- Crear una interfaz clara y responsive

## Retos

- Gestionar la ubicación del usuario
- Reducir peticiones sin perder datos frescos
- Mantener la coherencia en móvil y escritorio

## Decisiones técnicas

- Componentes con React
- Entorno de desarrollo con Vite
- Estilos con TailwindCSS
- Caché local con caducidad

## Destacado

- Búsqueda con atajo de teclado
- Ubicaciones favoritas guardadas
- Modo claro y oscuro
- Humedad, presión y condiciones detalladas

## Resultados / Impacto

- Mi laboratorio práctico de React
- Código disponible en GitHub

## Aprendizajes

### Lo que aprendí

- Gestionar estado y caché
- Decidir pensando en el uso diario

### Qué haría mejor

- Añadir tests a los flujos clave
- Mejorar el manejo de errores de red
