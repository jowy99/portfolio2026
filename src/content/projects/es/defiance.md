## Resumen

- Club ficticio de Valorant entre amigos
- Web pública, zona de staff y API
- Todavía sin publicar

## Objetivos

- Web pública en español e inglés
- Panel para gestionar candidatos y partidas
- Conexión con el bot de Discord
- API cubierta con tests

## Retos

- Web, API y bot con los mismos datos
- Solicitudes de Discord guardadas en la web
- Recuento de asistencia sin duplicados
- Tests sin depender de servicios externos

## Decisiones técnicas

- Web con React y Vite
- API con Hono y PostgreSQL
- Contrato compartido entre web y API
- Páginas prerrenderizadas en el build

## Destacado

- Panel de staff con acceso restringido
- Modo de desarrollo con datos de ejemplo

## Resultados / Impacto

- 85 tests de API superados
- Páginas públicas funcionando
- Mi proyecto más completo en estructura

## Aprendizajes

### Lo que aprendí

- Cómo encajan frontend, API y datos
- Definir bien el contrato entre partes

### Qué haría mejor

- Publicar una versión real
- Probar el panel con más personas
