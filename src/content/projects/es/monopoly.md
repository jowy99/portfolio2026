## Resumen

- Juego de Monopoly para terminal, en Java
- Tablero con 10 calles
- Hecho en solitario, aunque era para tres personas

## Objetivos

- Construir un juego funcional en Java
- Aplicar programación orientada a objetos
- Cumplir los criterios de la práctica

## Retos

- Definir la estructura del proyecto
- Afianzar los conceptos base de Java
- Asumir la carga de todo el equipo

## Decisiones técnicas

- Arquitectura simple y modular
- Clases para tablero, jugadores y banca
- Solo terminal, centrado en las reglas

## Destacado

- Turnos y dados
- Compra de calles
- Diagramas de clases, secuencia y uso

## Resultados / Impacto

- Proyecto terminado
- Código disponible en GitHub

## Aprendizajes

### Lo que aprendí

- Afianzar Java y la POO
- Dividir los problemas en pasos pequeños

### Qué haría mejor

- Ampliar las reglas del juego
- Añadir más pruebas
- Mejorar la entrada por consola
