## Resum

- Proposta de millora per a Directe C.B.
- Empresa d'ascensors i accessibilitat a Menorca
- Demo independent, no és la web oficial

## Objectius

- Presentar els serveis amb claredat
- Oferir la web en quatre idiomes
- Facilitar la petició de pressupost

## Reptes

- Treballar sense contingut de l'empresa
- Estabilitzar el disseny a totes les pantalles
- Preparar el desplegament en servidor propi

## Decisions tècniques

- Next.js amb App Router
- React, TypeScript i Tailwind CSS
- Sistema de traduccions propi
- Next.js darrere de Nginx

## Destacat

- Metadades i dades estructurades per idioma
- Mapa interactiu amb MapLibre

## Resultats / Impacte

- Demo publicada en quatre idiomes
- Pàgines de serveis i contacte
- Formulari simulat, en ser una demo

## Aprenentatges

### El que vaig aprendre

- Plantejar una proposta per a un negoci real
- Desplegar Next.js en servidor propi

### Què faria millor

- Parlar amb l'empresa abans de començar
