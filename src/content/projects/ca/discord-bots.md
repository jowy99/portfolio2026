## Resum

- Diversos bots de Discord des del 2021
- Sobretot de moderació
- Fets a mà, excepte el de Defiance, amb IA

## Objectius

- Automatitzar la moderació de servidors
- Afegir funcions per a cada comunitat
- Practicar amb Node.js en casos reals

## Reptes

- Adaptar-se a les necessitats de cada servidor
- Coordinar reclutament i convocatòries a Defiance
- Connectar un bot amb la web del club

## Decisions tècniques

- Desenvolupament amb Node.js
- TypeScript i discord.js als més recents
- Ordres de barra
- SQLite a La Lonja

## Destacat

- Warlock Club, SpArTa, Anham, Translator, WoWLK, Helper i ACWO Bot
- Vendetta, per a un servidor privat de World of Warcraft
- La Lonja: enquestes i recordatoris
- Defiance: reclutament, proves i votacions

## Resultats / Impacte

- Utilitzats en servidors de Discord
- Evolució cap a TypeScript i dades persistents

## Aprenentatges

### El que vaig aprendre

- Resoldre problemes reals d'altres persones
- Practicar JavaScript fora de classe

### Què faria millor

- Partir d'una base comuna
- Afegir tests a les ordres
