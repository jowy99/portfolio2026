## Resum

- App en Laravel per organitzar menjars
- Plats amb ingredients i etiquetes
- Agrupats en menús

## Objectius

- Desar plats amb les seves imatges
- Crear menús a partir d'aquests plats
- Administrar el contingut des d'un panell

## Reptes

- Modelar les relacions entre taules
- Gestionar les imatges de cada plat

## Decisions tècniques

- Laravel amb plantilles Blade
- Controladors d'una sola responsabilitat
- Relacions definides amb migracions

## Destacat

- Alta, consulta i edició de plats
- Creació de menús
- Panell d'administració

## Resultats / Impacte

- Aplicació amb migracions, controladors i vistes
- Codi disponible a GitHub

## Aprenentatges

### El que vaig aprendre

- Relacions entre taules a Laravel
- Separar el codi en controladors petits

### Què faria millor

- Afegir tests
- Documentar la instal·lació
