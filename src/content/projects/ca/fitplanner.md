## Resum

- Base d'una app d'entrenaments
- Amb API i autenticació
- Primeres pantalles en React

## Objectius

- Crear un registre i inici de sessió segurs
- Gestionar usuaris, rutines i progrés
- Practicar un backend ordenat

## Reptes

- Muntar React i Tailwind amb el backend
- Configurar les rutes a Express 5
- Prioritzar la base del projecte

## Decisions tècniques

- API amb Node.js i Express
- Rutes, controladors i middleware
- Dades a PostgreSQL
- Contrasenyes amb bcrypt i sessió amb JWT

## Destacat

- Registre i inici de sessió
- Rutes de rutines i progrés
- Pantalles d'accés i perfil

## Resultats / Impacte

- Backend estructurat
- Codi disponible a GitHub

## Aprenentatges

### El que vaig aprendre

- Autenticació amb JWT
- Ordenar un backend en capes

### Què faria millor

- Completar un flux petit de principi a fi
