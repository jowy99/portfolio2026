## Resum

- Club fictici de Valorant entre amics
- Web pública, zona de staff i API
- Encara sense publicar

## Objectius

- Web pública en espanyol i anglès
- Panell per gestionar candidats i partides
- Connexió amb el bot de Discord
- API coberta amb tests

## Reptes

- Web, API i bot amb les mateixes dades
- Sol·licituds de Discord desades a la web
- Recompte d'assistència sense duplicats
- Tests sense dependre de serveis externs

## Decisions tècniques

- Web amb React i Vite
- API amb Hono i PostgreSQL
- Contracte compartit entre web i API
- Pàgines prerenderitzades al build

## Destacat

- Panell de staff amb accés restringit
- Mode de desenvolupament amb dades d'exemple

## Resultats / Impacte

- 85 tests d'API superats
- Pàgines públiques funcionant
- El meu projecte més complet en estructura

## Aprenentatges

### El que vaig aprendre

- Com encaixen frontend, API i dades
- Definir bé el contracte entre parts

### Què faria millor

- Publicar una versió real
- Provar el panell amb més persones
