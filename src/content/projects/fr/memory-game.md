## Résumé

- Jeu de mémoire dans le navigateur
- Pensé pour des parties courtes
- Design et développement personnels

## Objectifs

- Créer un jeu simple et accessible
- Implémenter une logique claire et stable
- Garder une interface épurée

## Défis

- Garder une logique ordonnée
- Éviter la complexité inutile
- Rendre le jeu clair dès le premier essai

## Décisions techniques

- Logique interactive avec JavaScript
- Structure avec HTML
- Styles avec TailwindCSS

## Points forts

- Compte à rebours de 30 secondes
- Compteurs de paires et de coups
- Mécanique intuitive
