## Résumé

- Club fictif de Valorant entre amis
- Site public, espace staff et API
- Pas encore publié

## Objectifs

- Site public en espagnol et en anglais
- Panneau pour gérer candidats et matchs
- Connexion avec le bot Discord
- API couverte par des tests

## Défis

- Site, API et bot avec les mêmes données
- Candidatures Discord enregistrées sur le site
- Comptage des présences sans doublons
- Tests sans dépendre de services externes

## Décisions techniques

- Site avec React et Vite
- API avec Hono et PostgreSQL
- Contrat partagé entre site et API
- Pages prérendues au build

## Points forts

- Panneau staff à accès restreint
- Mode de développement avec données d'exemple

## Résultats / Impact

- 85 tests d'API réussis
- Pages publiques fonctionnelles
- Mon projet le plus complet en structure

## Apprentissages

### Ce que j'ai appris

- Comment s'articulent frontend, API et données
- Bien définir le contrat entre les parties

### Ce que je ferais mieux

- Publier une vraie version
- Tester le panneau avec plus de personnes
