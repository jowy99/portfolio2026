## Résumé

- Jeu de Monopoly pour terminal, en Java
- Plateau de 10 rues
- Réalisé seul, bien que prévu pour trois personnes

## Objectifs

- Construire un jeu fonctionnel en Java
- Appliquer la programmation orientée objet
- Répondre aux critères du travail

## Défis

- Définir la structure du projet
- Consolider les bases de Java
- Assumer la charge de toute l'équipe

## Décisions techniques

- Architecture simple et modulaire
- Classes pour le plateau, les joueurs et la banque
- Terminal uniquement, centré sur les règles

## Points forts

- Tours et dés
- Achat de rues
- Diagrammes de classes, de séquence et d'usage

## Résultats / Impact

- Projet terminé
- Code disponible sur GitHub
