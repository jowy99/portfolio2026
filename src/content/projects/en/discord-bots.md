## Summary

- Several Discord bots since 2021
- Mostly for moderation
- Handmade, except Defiance, built with AI

## Goals

- Automate server moderation
- Add features for each community
- Practice Node.js on real cases

## Challenges

- Adapting to each server's needs
- Coordinating recruitment and call-ups in Defiance
- Connecting a bot with the club's website

## Technical decisions

- Development with Node.js
- TypeScript and discord.js in the newest ones
- Slash commands
- SQLite in La Lonja

## Highlights

- Warlock Club, SpArTa, Anham, Translator, WoWLK, Helper and ACWO Bot
- Vendetta, for a private World of Warcraft server
- La Lonja: polls and reminders
- Defiance: recruitment, trials and votes

## Results / Impact

- Used on Discord servers
- Progress towards TypeScript and persistent data
