## Summary

- Fictional Valorant club among friends
- Public website, staff area and API
- Not published yet

## Goals

- Public website in Spanish and English
- Panel to manage candidates and matches
- Connection with the Discord bot
- API covered by tests

## Challenges

- Website, API and bot sharing the same data
- Discord applications saved on the website
- Attendance count without duplicates
- Tests that don't rely on external services

## Technical decisions

- Website with React and Vite
- API with Hono and PostgreSQL
- Contract shared between website and API
- Pages prerendered at build time

## Highlights

- Staff panel with restricted access
- Development mode with sample data

## Results / Impact

- 85 API tests passing
- Public pages working
- My most complete project in terms of structure

## Learnings

### What I learned

- How frontend, API and data fit together
- Defining the contract between parts well

### What I'd do better

- Publish a real version
- Test the panel with more people
