## Summary

- Improvement proposal for Directe C.B.
- Elevator and accessibility company in Menorca
- Independent demo, not the official website

## Goals

- Present the services clearly
- Offer the website in four languages
- Make requesting a quote easy

## Challenges

- Working without the company's content
- Stabilizing the design across screens
- Preparing deployment on my own server

## Technical decisions

- Next.js with App Router
- React, TypeScript and Tailwind CSS
- Custom translation system
- Next.js behind Nginx

## Highlights

- Metadata and structured data per language
- Interactive map with MapLibre

## Results / Impact

- Demo published in four languages
- Services and contact pages
- Simulated form, as it's a demo

## Learnings

### What I learned

- Planning a proposal for a real business
- Deploying Next.js on my own server

### What I'd do better

- Talk to the company before starting
